# Final Boss "Deus" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** At the top of the Paraíso, a guardian ofanim, a special Empíreo checkpoint that gives the wings, and a vertical flying chase into space against God (a giant eye of light inside three rings), where each ring runs its own light-based mechanic.

**Architecture:** All game changes are one-time migration scripts `tools/tNNN_*.py` that only add to `jogo.json` (same pattern as `tools/t124_cutulu_chefe.py`/`t136_menos_repeticao.py`), each with a pytest file that asserts the resulting JSON. Art is generated by Python into `assets/inimigos/ceu/deus/` and `assets/paraiso/` in the angels' palette, starting from the approved concept `olho_b` (`/tmp/claude-1000/-home-leo-Desktop-ADS-jogos/5a087315-fc8c-4eb8-bc9b-14c7d604c725/scratchpad/olho_conceitos.py`, function `conceito_b`). Boss/channeler/guardian logic goes in `InimigosParaiso` as groups; fight mode (start, camera, flight, lighting, background) goes in the Paraíso scene's own events as groups.

**Tech Stack:** GDevelop 5.6 (`jogo.json`), Python 3 (json, numpy, PIL), pytest.

**Spec:** `docs/superpowers/specs/2026-11-23-chefe-final-deus-design.md`

## Global Constraints

- Read `CLAUDE.md`. Every tunable number/color is a GDevelop variable with its initial value in `jogo.json`; never a literal inside an event (0, 1, -1, True/False and sign/clamp helpers are fine; `pato` damage formulas follow the existing `pato.vida -`, `invencivel`, `ResetObjectTimer(pato,"iframes")`, `ultimo_agressor`, `coice_vx` pattern).
- Migrations only add. If a variable/object/group/event already exists, keep it. Never rerun an old `tools/` script. Each script exits with "tNNN já foi aplicada" when its marker exists.
- Before touching `jogo.json`: `git status`; the user has uncommitted edits in `jogo.json` (and `jogo.json.autosave`). Apply each migration to both a HEAD copy and the working file and commit only the HEAD+migration version (technique in "Commit procedure" below).
- No comments in events; each new group's name says what it does. New groups use colors `colorR 74, colorG 176, colorB 228` like the rest.
- Objects are global (`d['objects']`); instances go in the Paraíso layout. Scene variables used by an external sheet must be declared in every scene that links it (`InimigosParaiso` is linked in `Paraiso` and `Teste`).
- `Deus` joins object group `Chefes` (HUD bar needs `barra_dist, barra_largura, barra_rastro_vel, nome, vida, max_vida, morto`). Its `chefe_final` is `True` (existing hook in `Portais` > "Liberação do portal final" sets scene var `chefe_final_morto`).
- Death in the fight uses the normal rule (`Jogador` > "Morte do Pato" → `Scene(hub)`, normal coin loss). Respawn at the Empíreo checkpoint uses the existing `waypoints[CurrentSceneName()]` (`ativo`, `x`, `y`) read by `Portais` > "Ponto de volta".
- Balance is for a fully upgraded duck (one fixed set of values).
- Art: pixel art, dark outline `(36,21,14)`, palette from `assets/inimigos/ceu/ofanim/idle_00.png`, drawn at native resolution and scaled 3x with NEAREST like the angels. Direction B: eye + three interlocking rings gold/blue/rose + sky-blue aura.
- Commit messages in Portuguese in the style of `git log`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Stage only the task's files (never `git add -A`).
- Test baseline: `python3 -m pytest -q tests --ignore=tests/test_perks.py` currently ends `19 failed`. Save that list before Task 1 (`... | grep -E "^(FAILED|ERROR)" | sed 's/ - .*//' | sort > /tmp/base_falhas.txt`); a task is green when `comm -13` against it is empty and its own tests pass.
